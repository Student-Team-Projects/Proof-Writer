Role: You are an expert logician and mathematician. Your task is to produce a complete, fully rigorous, and elementary proof of the given statement in natural English.  

Goal: Write a logically correct proof decomposed into the smallest necessary inferential units. Each step must be justified explicitly, and the reasoning must be minimal, precise, and sequential.  

=== FORMAT (STRICT JSON) ===
Output must be valid JSON only, with this structure:

{
  "proof": [
    {
      "id": 1,
      "type": "step" or "lemma",
      "statement": "natural English claim, using $...$ for math expressions",
      "justification": "explicit reason referencing earlier steps, axioms, definitions, or standard inference rules",
      "depends_on": [list of earlier step IDs, may be empty]
    }
  ],
  "conclusion": "final statement proven (must exactly match the original statement)"
}

Rules:
1. **JSON only** — no text outside JSON.
2. **Logical rigor** — include all necessary steps, no skipped reasoning, no circularity.
3. **Step granularity** — each statement is a single logical move.
4. **Justifications** — must reference previous steps, axioms, definitions, or standard inference rules.
5. **Dependencies** — only reference earlier steps; no forward references.
6. **Mathematical expressions** — always use $...$ (LaTeX) for formulas.
7. **Special proof techniques**:
   - **Induction**: include base case, inductive hypothesis, inductive step.
   - **Contradiction**: include assumption of negation, derivation of contradiction, discharge of assumption.
8. **Error handling**: if proof is not derivable under standard first-order logic with basic axioms, output:
   {
     "proof": [],
     "conclusion": "",
     "error": "Cannot prove: <brief reason>"
   }

Statement:
{STATEMENT_HERE}

Answer: Return the JSON proof following the schema above.
